# DDR Report Generator

An AI-powered web application that automatically generates a 
Detailed Diagnostic Report (DDR) from building inspection documents.

---

## What It Does

Upload two PDF documents — an Inspection Report and a Thermal 
Imaging Report — and the system will:

- Extract and analyse all observations from both documents
- Cross-reference thermal data with physical inspection findings
- Identify root causes, severity levels, and recommended actions
- Generate a professionally formatted Word document (.docx)

---

## Tech Stack

| Component        | Technology                     |
|------------------|-------------------------------|
| UI / Frontend    | Streamlit (Python)             |
| AI Model         | LLaMA 3.3 70B via Groq API     |
| PDF Extraction   | PyMuPDF (fitz)                 |
| Report Building  | python-docx                    |
| Environment      | python-dotenv                  |

## How to Run Locally

**1. Clone the repository**
```bash
git clone https://github.com/yourusername/ddr-generator.git
cd ddr-generator
```

**2. Create and activate virtual environment**
```bash
python -m venv venv

# Windows
venv\Scripts\activate

# Mac / Linux
source venv/bin/activate
```

**3. Install dependencies**
```bash
pip install -r requirements.txt
```

**4. Add your API key**

Create a `.env` file in the root folder:
```
GROQ_API_KEY=your_groq_api_key_here
```

Get a free API key at: https://console.groq.com

**5. Run the app**
```bash
streamlit run app.py
```

Open your browser at `http://localhost:8501`

## Output Report Structure

The generated DDR contains the following sections:

1. **Property Issue Summary** — Overview table of all impacted areas
2. **Area-wise Observations** — Negative side, positive side, and 
   thermal findings per area
3. **Probable Root Cause** — AI-identified causes with evidence
4. **Severity Assessment** — High / Moderate / Low rating per area
5. **Recommended Actions** — Phased action plan (Immediate, 
   Short-term, Long-term)
6. **Additional Notes** — Checklist findings and building-level concerns
7. **Missing or Unclear Information** — Explicitly flagged gaps 
   marked as "Not Available"

## Key Design Decisions

**Why Groq + LLaMA 3.3 70B?**
Free tier with high rate limits. The 70B model produces 
accurate structured JSON output reliable enough for 
professional report generation.

**Why JSON as intermediate format?**
Having the AI return structured JSON (instead of raw text) 
allows the report builder to format each section independently.
This makes the system easy to extend — add a new section by 
updating the prompt and report builder only.

**Why Streamlit?**
Fastest way to build a clean, usable interface for a 
document processing tool without needing a separate frontend.

**Handling missing data**
The system never invents facts. Any information absent from 
the source documents is explicitly marked as "Not Available" 
in the output report.

**Generalisation**
The system is not hardcoded to the sample documents. It works 
on any building inspection PDF + thermal imaging PDF with 
similar structure.
